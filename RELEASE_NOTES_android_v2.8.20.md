# Remote Key Android 2.8.20 (build 46)

Inactive/disconnected widgets use a black background by default at every size.
Connected widgets remain blue. Waiting, sending, success and error feedback retain
their existing colors and three-second result reset. The 1×1 size and responsive
layouts introduced in 2.8.19 are included.

Existing Android widget rendering checks verify black when disconnected and blue
while connected. No device setup, firmware or watch update is required.
