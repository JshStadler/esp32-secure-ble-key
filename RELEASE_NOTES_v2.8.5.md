# Remote Key Android v2.8.5

Android version code: **31**. Minimum Android: **7.0 / API 24**.

- App Settings now has an About section showing the installed version and build
  number. The text can be selected and copied for troubleshooting.
- The label comes from the build metadata, including the `-test` suffix on test
  builds, so it remains accurate for later releases.

Android-only update. ESP firmware and Garmin apps remain at v2.8.4; no firmware
update is required for this settings change.

## Google Play notes

App Settings now shows the installed app version and build number under About.
